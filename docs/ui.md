# MineCircuit 画面構成

作成日: 2026-10-19 / 仕様: [spec.md](spec.md) / 設計: [design.md](design.md)

UIプロトタイプ（[prototype/index.html](../prototype/index.html)）で確認した画面構成。計算は未実装で、計算欄は「表示例・未実装」と明記している。

## 全体の配置

![3D表示とブロックの選択](images/ui-3d.png)

| 場所 | 内容 |
| --- | --- |
| 上のバー1段目 | 設計図の選択・開く、Modpack、設計図の情報（寸法、ブロック数、種類、nbt付きの数、エンティティ数、バージョン、編集回数） |
| 上のバー2段目 | 3D/2D、視点（斜め・上・正面・横、全体を表示）、段の移動と表示方法、補助表示（グリッド・座標軸・略称）、選択と強調の解除、編集（元に戻す・やり直す・書き出し）、パネルの表示、全画面 |
| 左パネル | 置くブロック、ブロック一覧（全体／この段、検索、強調）、使っているMod |
| 表示部分 | 3D/2D表示。左上に縦のツールバー。左下に結果の表示（計測、お知らせ、書き出し） |
| 段の一覧 | 段ごとのブロック数と表示・非表示。「すべて表示」「この段だけ表示」 |
| 右パネル | 選択中のブロック（ID、位置、ブロック状態、生データのツリー）、計算結果 |
| 下の状態表示 | マウス位置、選択中のブロック |

画面の幅が900pxより狭いときは、上から「上のバー、表示部分、段の一覧、左パネル、右パネル」の順に1列に並べる。

## 段の一覧

![段の一覧と、上の段を半透明にした表示](images/ui-layers.png)

基板設計ツールのレイヤー一覧を元にした。段ごとにブロック数を出し、左の丸で表示・非表示を切り替える。段の表示方法（すべて・上を消す・上を半透明・この段だけ）と組み合わせて使う。

## 2D表示と計測

![2D表示で2点間を計測](images/ui-2d-measure.png)

2D表示は、選んだ段を真上から見たマス目。上が北（−Z）。1つ下の段を薄く出す。マスが大きいときは、ブロック名の略称を出す。

計測ツールは、2つのブロックの座標の差、直線距離、軸に沿った距離、囲む範囲を出す。軸に沿った距離は、シャフトやベルトを引く長さの目安になる。

## 編集

![2Dでの編集](images/ui-edit-2d.png)

![編集した設計図の3D表示](images/ui-edit-3d.png)

- 2D：マスをクリックして置く。埋まったマスは置き換え
- 3D：クリックした面の隣に置く。何もない所は今の段の床に置く。Shift+クリックで置き換え
- 置くブロックは、左パネルで設計図にあるブロックから選ぶか、IDを入力する。スポイトで表示中のブロックから取ることもできる
- 置いた段が隠れる表示のときは、その段へ自動で移る

## ツール

表示部分の左上の縦のツールバー。回路図エディタのツールバーを元にした。

| ツール | キー | 内容 |
| --- | --- | --- |
| 選択 | V | ブロックの情報を右パネルに出す |
| 計測 | M | 2つのブロックの距離を測る |
| つながり | C | 隣り合う同じ種類のブロックをまとめて強調する。回転や配管のつながりではない |
| プローブ | － | マウスの下のブロックの回転数と応力を、値の出どころ付きで右パネルに出す。クリックすると、回転でつながったブロック（ネットワーク）を青緑で強調する |
| 置く | B | ブロックを置く・置き換える |
| 消す | E | ブロックを消す |
| スポイト | I | クリックしたブロックを「置くブロック」にする |

## キー操作

| キー | 操作 |
| --- | --- |
| V / M / C / B / E / I | ツールの切り替え |
| R | 水平に回す（north→east→south→west、軸は x↔z） |
| Shift+R | 縦にする（軸 y、facing up/down） |
| Ctrl+Z / Ctrl+Y | 元に戻す / やり直す |
| Delete | 選択中のブロックを消す |
| G | グリッドの表示切り替え |
| PageUp / PageDown | 段の移動 |
| Esc | 選択の解除 |

R / Shift+R は、置くツールのときは置くブロックを回す。ほかのツールでは、選択中のブロックがあればそのブロックを（元に戻せる操作として）回し、なければ置くブロックを回す。回せる向きがなければ、下の状態表示に「このブロックには回せる向きがありません」と出す。Modpackを読んでいれば、そのブロックが取りうる値の範囲で回す。

## プロトタイプについて

- `prototype/index.html` をChromeかEdgeで開くと動く。Three.js を CDN から読み込むので、ネット接続が必要
- 例として入っている設計図は、コードで生成したデータ（小さな加工ラインのデモ、負荷テスト、新規）だけ。他人が作った設計図は含めない。デモの配置は見た目の例で、ゲームで動くことは確かめていない
- 書き出しは、`.nbt` を作って読み直し、配置と状態が一致するかの確認までは全環境で動く。保存はブラウザが保存先の選択に対応している場合だけ
- 計算、Modpackの読み込み、範囲操作は未実装
