## 全体の配置

![3D表示とブロックの選択](images/ui-3d.png)

| 場所 | 内容 |
| --- | --- |
| 上のバー1段目 | 設計図（新規・開く・書き出し（.nbt））、Modpack、設計図の情報（寸法と「大きさを変える…」、ブロック数、種類、nbt付きの数、エンティティ数、バージョン、書き出してからの変更の回数） |

画面の幅が900pxより狭いときは、上から「上のバー、表示部分、段の一覧、左パネル、右パネル」の順に1列に並べる。

## 段の一覧

![段の一覧と、上の段を半透明にした表示](images/ui-layers.png)

基板設計ツールのレイヤー一覧を元にした。段ごとにブロック数を出し、左の丸で表示・非表示を切り替える。段の表示方法（すべて・上を消す・上を半透明・この段だけ）は上のバー2段目の選択だけで切り替え、段の一覧には同じ働きのボタンを置かない。段の一覧の丸は、段を1つずつ隠すためのもの。隠した段は表示方法によらず出さない。「隠した段を戻す」で、隠した段をまとめて表示に戻す（表示方法は変えない）。

## 2D表示と計測

![2D表示で2点間を計測](images/ui-2d-measure.png)

2D表示は、選んだ段を真上から見たマス目。上が北（−Z）。1つ下の段を薄く出す。マスが大きいときは、ブロック名の略称を出す。

ブロックの向き（#166）は、マスが 12px 以上のときにマスの上へ白い線（暗い縁付き）で描く。組み間違いに表示で気づけるようにする。

- `facing`・`horizontal_facing` が水平なら、その向きへの矢印（プレスやファンの向き）
- `facing=up` は丸に点、`facing=down` は丸に ×（上から見て、こちらを向く・向こうを向く）
- `axis=x`・`axis=z` は、その軸に沿った両端に横棒の付いた線（シャフトの向き）。`axis=y` は丸
- `horizontal_facing` と `facing` の両方があるときは `horizontal_facing`、向きと軸の両方があるときは向きを描く。略称は印の上に書く。検索で薄くしたブロックには描かない

2D表示の動かし方。大きい設計図でも端まで見られるようにする。

- ホイール：マウスの位置を中心に拡大・縮小する
- 中ボタンでドラッグ、または空白キーを押したまま左ドラッグ：表示を動かす
- 上のバーの視点の「全体を表示」：設計図の段全体が入る大きさに戻す。別の設計図を開いたときも全体を表示にする

視点の「斜め・上・正面・横」は3D表示だけで使う。

計測ツールは、2つのブロックの座標の差、直線距離、軸に沿った距離、囲む範囲を出す。軸に沿った距離は、シャフトやベルトを引く長さの目安になる。

## 回転の表示

補助表示の「回転」を入れると、計算で回るとしたブロックを、速さの段階で色分けする。力（回転）がどこまで、どの速さで伝わっているかを、表示部分で確かめるためのもの。数値は、ブロックを選ぶか、プローブでマウスを重ねて1つずつ見る。

| 色 | 意味 |
| --- | --- |
| 灰 | 止まっている（動力源につながっていない、向きや速さが衝突している） |
| 緑 | 遅い（中速より遅い） |
| 青 | 中速（Create の設定の中速以上、高速より遅い。初期値では 30 RPM 以上） |
| 紫 | 高速（Create の設定の高速以上。初期値では 100 RPM 以上） |
| 赤 | 過負荷で止まっている（色は止まる前の速さではなく赤） |

- 3D：ブロックを色の箱で包み、回るブロックには、回る向きを示す輪の矢印を軸に垂直に付ける。輪は、軸の正の向きから見て、正の回転数なら反時計回りに見える（Create と同じ向き）
- 2D：マスを色で塗り、マスが大きいときは回転数を符号付きで書く。上下の軸で回るブロックは、上から見た向き（↺ ↻）も書く
- 表示部分の右下に色の凡例を出す
- 回して見せる動き（アニメーション）はしない

## 編集

![2Dでの編集](images/ui-edit-2d.png)

![編集した設計図の3D表示](images/ui-edit-3d.png)

- 2D：空きマスをクリックして置く。埋まったマスは Shift+クリックで置き換え（3D と同じ。#164）。Shift なしでクリックすると置かずに、状態表示に置き換え方を出す
- 3D：クリックした面の隣に置く。何もない所は今の段の床に置く。Shift+クリックで置き換え
- 枠のすぐ外にも置ける（#191）。3D は端のブロックの面の外、2D は格子の外側に1マス分の余白を点線で出し、そこをクリックする。置くと、はみ出した分だけ設計図を広げる（下の「設計図の大きさ」）
- ドラッグで一直線に置く（#161。回路エディタの配線にあたる）。押した所の置く先（2D は押したマス、3D は押した面の隣か床のマス）が始点で、離した所までを、始点からの差が一番大きい軸（x・y・z）に沿った直線で埋める
  - ドラッグ中は、置くマスを見本で出し、線の端から端を枠で囲む。離すと置く。1回の「元に戻す」で全部消える
  - `axis` を持つブロック（シャフトなど）は、軸を引いた向きにする。向き（`facing` など）は置くブロックの欄のまま。曲がり角に歯車を入れるのは後で足す
  - 線が枠の外へ出るときは、線が入るように設計図を広げる（#191）
  - 埋まっているマス・広げられない所・ゲームで置けないマスは飛ばし、「埋まっているマス・範囲の外・置けないマスの n 個は飛ばしました。」と出す。置き換えはしない
  - 3D では、ブロックか床を押して引くと線になり、カメラは回らない。カメラを回すときは、設計図の外から左ドラッグする（右ドラッグの移動、ホイールの拡大・縮小は今までどおり）
  - 2D・3D とも、動かさずに離したときはふつうのクリック
- 置くブロックは、左パネルの「置くブロック」の棚から選ぶ。棚はゲームのクリエイティブのインベントリのように、ブロックの絵（アイコン）を格子に並べたもの
  - 棚の上の「Mod」の欄で、棚に並べるものを選ぶ。選べるのは「この設計図」（設計図にあるブロック状態）と、Modpack を読んでいれば Mod（namespace）ごと、Modpack がなければ「基本の部品」。欄に Mod の名前か namespace の一部を入れると候補が出るので、クリックか ↑↓ と Enter で選ぶ。候補は、設計図で使っている Mod を先に、残りを名前順に並べる。Mod の中のブロックは表示名の順
  - 「ブロック」の欄に文字を入れると、選んでいる Mod の中を日本語名・英語名・ID の一部で絞り込む。`create:shaft[axis=y]` のような ID と状態は、Enter でそのまま使う
  - アイコンは、ブロックの見た目（モデルとテクスチャ）を斜め上から描いた小さな画像。見た目が分からないブロックや、テクスチャで描けないときは、ブロックの色と略称。名前と ID はマウスを重ねると出る
  - クリックすると置くブロックになり、置くツールに切り替わる。Mod から選んだときの状態（向きなど）は、ブロック状態の定義の最初の組み合わせ。状態は上の欄で取りうる値から選ぶ。R / Shift+R でも回せる。置くブロックの下の「回す（R）」「縦にする（Shift+R）」ボタンも同じ（#162）
  - 棚や ID の入力で、Create の回るブロックの回転軸を決める状態（`axis`・`facing`）がなければ補う（`create:shaft` は `create:shaft[axis=y]`、`create:creative_motor` は `facing=north`）。書いた値は変えない
  - 補えない（`axis=w` のように値が読めない）ブロックも置けるが、置いた時点で「計算から外れます」と下の状態表示に出す
  - Modpack がないときは、「この設計図」と「基本の部品」と ID の入力。「基本の部品」は、計算で扱える Create の基本の部品（シャフト・歯車・大きな歯車・ギアボックス・クラッチ・ギアシフト・チェーンドライブ・クリエイティブモーター・ハンドル・水車・プレス・ミキサーなど）を、回転軸の決まった既定の状態（`axis=y`、`facing=north` など）で並べる（#162）。名前はアプリで書いた短い名前で、Mod の翻訳ファイルは使わない。アイコンはブロックの色と略称（テクスチャは Modpack から読むので、ないときは描かない）。設計図が空なら、最初から「基本の部品」を開く
  - スポイトで表示中のブロックから取ることもできる
  - 最近使ったブロックは、表示部分の下のクイックバーからも選べる（下の「クイックバー」。#197）
- 置くとき、隣に回転でつながるブロック（Create のシャフト・歯車・モーターなど）があれば、つながる向きに自動で合わせる。シャフトの端にシャフトを置けば同じ軸、歯車の横に歯車を置けば噛み合う軸、モーターは軸をそのシャフトへ向ける。3D ではクリックした面の側を優先する。つながる相手がなければ、置くブロックの欄の向きのまま
- Alt を押しながら置くと、自動で合わせず、置くブロックの欄の向きのまま置く
- ゲームで置けない（置いても外れて落ちる）場所には置かせず、理由を下の状態表示に出す。置く前の見本は赤くなる。今入れている規則は Create の歯車だけ：大きい歯車の横（軸に垂直な4方向）には歯車を置けず、大きい歯車は小さい歯車の横に置けない（隣の軸がこちらを向いていれば置ける）。噛み合わせるときは斜めに置く。自動で向きを合わせるときは、置ける向きだけから選ぶ
- 置き方の補助（3D）：歯車を置くとき、歯車をクリックすると、ゲームの置き方の補助と同じく噛み合う位置に置く。大きさが違う歯車なら、クリックした点に近い側の斜めに同じ軸で。小さい歯車どうしなら、クリックした点に近い向きの横に同じ軸で。大きい歯車どうしなら、軸の向きに1つずらした斜めに、軸を直角にして。置ける位置がなければ、ふつうにクリックした面の隣に置く。歯車の真ん中の軸の部分をクリックしたときと、Alt を押しているときは補助を使わない。置く前の見本も補助の位置に出す
- R で選択中のブロックを回したとき、回した向きが置けない向きなら回さずに理由を出す
- 開いた設計図に規則に合わないブロックがあれば、計算結果の「問題」にその位置を出す
- 置いた段が隠れる表示のときは、その段へ自動で移る

### 書き出していない変更

- 上のバーの設計図の情報に「書き出してから n 回の変更」を出す。置く・消す・回す・範囲の操作・元に戻す・やり直すを、それぞれ1回と数える。変更がなければ「変更なし」
- 書き出し（.nbt）で保存できたら 0 に戻す。保存先を選ぶ画面でやめたときは戻さない。書き出しの途中にした変更は、書き出していない変更として残る
- 元に戻して書き出したときと同じ中身になっても、回数は 0 に戻さない
- 書き出していない変更があるとき、設計図を入れ替える前に確かめる
  - 「ファイルを開く…」とファイルのドロップ：ファイルを選んだあと、開く前に「書き出していない変更が n 回あります。続けると、この変更はなくなります。続けますか。」と確かめる。やめると今の設計図のまま
  - 「新規…」：作る画面に「書き出していない変更（n 回）はなくなります」と出し、「作る」を押したら入れ替える
  - Modpack の読み込みは設計図を入れ替えないので、確かめない
- ページを閉じる・再読み込みするときは、ブラウザの確認を出す（文はブラウザが決める）
- デスクトップ版でウィンドウを閉じるときは、「書き出していない変更が n 回あります。閉じると、この変更はなくなります。閉じますか。」と確かめる。やめると閉じない。閉じてよければ自分で閉じるため、Tauri の許可 `core:window:allow-destroy` を足した（#173）

### クイックバー

表示部分の下の中央に浮かぶ横長のバー（#197）。ゲームのホットバーのように、最近使ったブロックと、よく使う操作を置く。棚へ戻らずに置くブロックを替えるためのもの。

- 左：最近のブロック（9 マス）。マスにはアイコン（なければ色と略称）と、1〜9 の番号を出す。名前と ID はマウスを重ねると出る
  - 棚・ID の入力・スポイトで置くブロックにしたブロックを、左に足す。同じブロック（ID が同じ）は1マスにまとめて左へ動かす。9 マスを超えたら、右端の古いものから消す
  - 置くブロックを回す・状態を選び直すと、そのマスの状態（向き）も変える。並びは変えない
  - クリックか 1〜9 キーで、そのブロックを置くブロックにして置くツールにする。バーから選んだときは並びを変えない
  - 右クリックで固定・固定の解除。固定したマスは左端にまとめ、押し出されない。固定したマスの状態は、回しても変えない（固定したときの向きのまま）。固定したマスに印を出す
  - 今の置くブロックと同じ ID のマスを枠で示す
- 右：操作のボタン。初期は「元に戻す」「やり直す」「回す（R）」「縦にする（Shift+R）」。キーと同じ動き。元に戻す・やり直すは、できないときは押せない
- 右端の「…」で、操作の出し入れ（チェック）と並べ替え（↑↓）をする。「初期に戻す」で初期の並びに戻す
- 最近のブロック・固定・操作の並びは、アプリの中（ブラウザ版はブラウザの localStorage、デスクトップ版はウィンドウの localStorage）に保存し、次に開いても残す。外部には送らない。保存できないときは、その回だけ覚える
- 設計図を開いていないときも出す（置くブロックは設計図がなくても選べる）。最近のブロックがなければ「棚から選んだブロックがここに並びます」と出す

## 右パネル

上下2つに分け、それぞれの中でスクロールする。ブロックを選んで上が長くなっても、計算結果は下に残る。

- 上「プロパティ」：選択中のブロック、または選択範囲（「範囲の選択と一括操作」）。プローブを使っている間と強調している間は、その下にプローブの欄

選択中のブロックの欄（#158）。ブロックを選ぶだけで、回転数と応力が分かるようにする。

- 名前・ID・位置・ブロック状態・生データのツリー
- ブロック状態の値は、選んで直せる（#165）。候補は、Modpack を読んでいればそのブロックが取りうる値、なければよく使う項目（`axis`・`facing`・`horizontal_facing`・`true`/`false`）の一般の値。候補が分からない項目は文字を打って直す。1回の変更が1回の「元に戻す」で戻る。生データはそのまま。ゲームで置けない向きなら直さず、理由を下の状態表示に出す
- 計算の値：プラグインごとに、そのブロックの値（回転数・応力・輸送量など）を出どころの印つきで出す。プローブで出すものと同じ
- ネットワーク：属するネットワークの名前（ネット一覧の「ネットワーク n」）。「強調」でそのネットワークを強調する
- 問題：そのブロックが入る問題（ネットワーク全体の問題も含む）を、重さの印つきで出す
- 何も選んでいないときは、設計図全体のまとめ（計算のまとめの行と、重さごとの問題の件数）を出す

プローブの欄は、マウスの下のブロックの値の一時表示（値だけ。出どころは選択中のブロックの欄で見る）と、強調の解除だけにする。
- 下「計算」：計算の状態（計算中など）と、次のタブ。タブの名前に件数を出す（ネットワーク・問題・入出力・仮定）

| タブ | 内容 |
| --- | --- |
| まとめ | プラグインごとの合計（「ネットワーク n／過負荷 m／止まっている k」など）。物の入口を置いたときは「生産ライン」の行（入る数・律速の機械・出る数。#168）も出し、押すと律速の機械へ移る |
| ネットワーク | ネット一覧。行を押すとそのネットワークを強調する |
| 問題 | プラグインの問題を、重さ（エラー・警告・情報）ごとに分けて出す。ネットワーク全体のものは1件にまとめる。3D・2Dで強調するのはエラーだけ。位置を押すとそのブロックへ移る（重さの決め方は docs/design.md「calc：計算プラグイン」） |
| 入出力 | 仮の入出力の一覧と、置く種類の選択（ツールバーの「仮の入出力」）。仮の入出力のツールに替えると、このタブを開く |
| 仮定 | 何を仮定して計算したか |

## 範囲の選択と一括操作

範囲を選んで、まとめて消す・塗る・置き換える・動かす・回す・反転する・コピーして貼り付ける（#129）。どれも1回の「元に戻す」で戻る。

### 範囲を選ぶ

選択ツール（V）で選ぶ。範囲は箱（x・y・z の最小と最大）1つだけ。

- クリック：そのブロック1つを選ぶ（今までと同じ）。範囲は 1×1×1 の箱になる。空きマスをクリックすると選択を解除する
- Shift+クリック：最初にクリックしたブロック（起点）と、今クリックした所を角にした箱に広げる。段をまたいでよい（3D では別の段のブロックを、2D では段を変えてからクリックする）。空きマスも角にできる
- 2D でドラッグ：今の段の長方形を選ぶ。Shift+ドラッグで、起点の段から今の段までの高さにする
- Ctrl+A：設計図全体を選ぶ
- Esc：選択を解除する（貼り付けの途中なら、貼り付けをやめる）
- 選んでいる範囲は、3D では箱の線で、2D では範囲に入る段で長方形の線で示す。範囲の外の段にいるときは、2D の長方形を点線にする

### 範囲のツールバー

2つ以上のブロックが入る範囲を選んでいるとき、選んだ範囲の近くに浮かぶツールバーを出す（#160）。範囲の操作をする場所を、2D と 3D で同じ形にそろえる。

- 出す所：範囲の上に、範囲の右端にそろえて出す。上に入らなければ範囲の下に出す。表示部分の外にはみ出すときは内側に寄せる。2D では拡大・移動と段の切り替えに、3D ではカメラの動きについていく
- 貼り付けの見本を出している間は出さない
- 左から：中のブロックの数、「消す」「塗る」（と「空きだけ」）「置き換え…」、「右に回す」「左に回す」「x 軸で反転」「z 軸で反転」、「コピー」「切り取り」「複製」「貼り付け」、「全体を選ぶ」。ボタンにマウスを重ねるとキーを出す
- 「x 軸で反転」は x の向きを逆に（東と西を入れ替える）、「z 軸で反転」は z の向きを逆に（北と南を入れ替える）
- 「貼り付け」は Ctrl+V と同じ。切り抜きがなければ押せない。「全体を選ぶ」は Ctrl+A と同じ
- 「置き換え…」を押すと、ツールバーの下に置き換えのフォームを開く（もう一度押すと閉じる）。「置き換える物」（範囲の中にある状態から選ぶ。数付き）と「置く物」（今の置くブロック）、「向きを引き継ぐ」を選んで「置き換え」で実行する。生データは消える

### 右パネル「選択範囲」

2つ以上のブロックが入る範囲を選んでいるときに出す（1つのときは今の「選択中のブロック」）。操作はツールバーに置き、右パネルには座標と大きさだけを出す（#160）。

- 範囲の最小・最大の座標と大きさ。数を打って直せる（段は1始まりで出す）
- 「選択の解除」

### まとめて変える

| 操作 | キー | 内容 |
| --- | --- | --- |
| 消す | Delete | 範囲の中を空きにする |
| 塗る | F | 範囲の中を置くブロックにする。ツールバーで「空きだけ」を選べる（初期値は空きだけ）。生データは消える |
| 置き換え | － | ツールバーの「置き換え…」から。ある状態を置くブロックに変える。向きのプロパティ（`axis`・`facing` など）を置く物も持っていれば、元の向きを引き継ぐ |

### 動かす

範囲の中のブロックを、生データごと動かす。範囲も一緒に動く。

- 矢印キー：水平に1マス。2D では画面の上下左右（上が −Z）。3D では、画面の上下左右に一番近い x・z の向き
- Shift+PageUp / Shift+PageDown：上下に1段（PageUp / PageDown だけなら今までどおり段の移動）
- 行き先に範囲の外のブロックがあれば、動かさず「動かす先にブロックがあります（3 個）」と出す。重ねて上書きするときは Ctrl を押しながら動かす
- 設計図の外へはみ出すときは、設計図を広げる（下の「設計図の大きさ」）
- 範囲の中のエンティティ（額縁など）と、範囲の中のブロックに付けた仮の入出力も一緒に動く

### 回す・反転する

範囲を、範囲の中心のマス（中心が2つのマスの間なら小さい側のマス）を軸に回す・反転する。ブロックの向きのプロパティも、ゲームの回転・反転の規則で変える。

- R：上から見て右回りに 90°。Shift+R：左回りに 90°（範囲を選んでいないとき、範囲が1マスのときは、今までどおりブロックを回す・縦にする）。ツールバーの「右に回す」「左に回す」も同じ
- 反転はツールバーのボタンから（「x 軸で反転」は x の向きを逆に、「z 軸で反転」は z の向きを逆に）。反転は範囲の中で写すので、範囲は動かない
- 回すと範囲の大きさの x と z が入れ替わる。軸のマスは動かないので、4回回すと元の位置に戻る。はみ出せば設計図を広げる。ほかのブロックに重なるときは、動かすときと同じく止めて理由を出す（Ctrl+R で上書き）
- 範囲の中のエンティティ（額縁など）は、位置と向きも回す。範囲の中のブロックに付けた仮の入出力は、位置を回す。選択範囲は回したあとの範囲になる
- 生データの中の座標（機械アームの行き先など）も、回転・反転に合わせて書き直す（Mod ごとの規則。docs/create-stress.md「回転・反転」）。範囲の外のブロックを指していたものは、回しても相手が一緒に動かないので、状態表示に「生データの座標を直せないブロックがあります（n 個）」と出す
- 縦（x・z の軸のまわり）の回転はしない

### コピー・切り取り・貼り付け

- Ctrl+C：範囲の中（ブロック・生データ・エンティティ）をアプリの中の切り抜きに写す。空きマスは写さない（貼り付けで空きにしない）
- Ctrl+X：写してから消す
- Ctrl+V：貼り付けの見本を出す。見本はマウスについて動き、置くときと同じく、3D はクリックした面の隣、2D は今の段のマスに、切り抜きの最小の角を合わせる。R / Shift+R で見本を回す。クリックで貼る。Esc でやめる
- 見本は、重なるブロックがあれば赤くし、クリックしても貼らない（Ctrl+クリックで上書き）
- 1回貼ったら見本を消す。続けて貼るときは、もう一度 Ctrl+V
- 見本を出している間は、今のツールの代わりに見本がクリックを受け取る。ツールを切り替えると貼り付けをやめる
- Ctrl+D：複製。範囲を写し、すぐ隣（x の正の向き）に貼る見本を出す
- 貼ったあとは、貼った所が新しい選択範囲になる
- 切り抜きは別の設計図を開いても残る（アプリを閉じると消える）。別の設計図に貼ると、Mod の違いはそのまま（足りない Mod の検出に出る）

### 設計図の大きさ

- 動かす・回す・貼り付け・置く（枠のすぐ外に置いたとき）で設計図の外へはみ出すときは、はみ出す分だけ設計図を広げる。最小の角が負の向きにはみ出すときは、全体をずらして 0 から始まるようにする（座標が変わるので、状態表示で知らせる）。選択範囲と仮の入出力も一緒にずらす
- 広げられるのは各辺 512 まで。超えるときは操作をやめて理由を出す
- .litematic でリージョンが2つ以上あるときは、範囲（置くときはクリックしたブロック）が入っているリージョンを広げる。ほかのリージョンに重なるときは、操作をやめて理由を出す
- どれも1回の「元に戻す」で、元の大きさと中身に戻る

**大きさを変える（#191）。** 上のバー1段目の寸法の横の「大きさを変える…」で、次の画面を出す。

- x−・x+・y−・y+・z−・z+ の6つの欄に、その向きに足すマス数を入れる（初期値 0）。マイナスで縮める。変えたあとの寸法を欄の下に出す
- リージョンが2つ以上なら、どのリージョンを変えるかを選ぶ（初期値は最初のリージョン）
- 縮めて消えるブロックがあれば「縮めた所にあるブロック n 個が消えます」と出し、ボタンを「ブロックを n 個消して変える」にする（押すことが確かめになる）。消えるマスのエンティティも消える
- 各辺は 1 以上 512 以下。外れるとき・ほかのリージョンに重なるときは「変える」を押せず、理由を出す
- 「余白を詰める」：各リージョンを、ブロックとエンティティが入る一番小さい箱に縮める。何もないリージョンは 1×1×1 にする。詰める所がなければ押せない
- 負の向きに広げた・縮めたときは、座標がずれることを状態表示で知らせる

## ツール

表示部分の左上の縦のツールバー。回路図エディタのツールバーを元にした。

| ツール | キー | 内容 |
| --- | --- | --- |
| 選択 | V | ブロックの情報を右パネルに出す。Shift+クリック・2D のドラッグで範囲を選ぶ（「範囲の選択と一括操作」） |
| 計測 | M | 2つのブロックの距離を測る |
| ネットワーク | C | クリックしたブロックと、回転でつながったブロック（ネットワーク）を青緑で強調する。プローブのクリックと同じ強調。ほかのツールに替えても強調は残る（「強調」） |
| 同じブロック | S | 隣り合う同じ種類のブロックをまとめて強調する。回転や配管のつながりではない（#163 までは「つながり（C）」） |
| プローブ | P | マウスの下のブロックの回転数と応力、運ぶブロックの輸送量、機械の処理時間（[create-throughput.md](create-throughput.md)）を、右パネルのプローブの欄に一時的に出す（出どころは、ブロックを選んで選択中のブロックの欄で見る）。クリックすると、回転でつながったブロック（ネットワーク）を青緑で強調する。ほかのツールに替えると、右パネルのプローブの欄と強調を消す |
| 仮の入出力 | O | ブロックをクリックして、仮の動力源（回転数、供給）や仮の負荷（応力）、物の入口（アイテム、個/秒）をそのブロックに付ける。面は選ばない（3D でも 2D でも同じ）。同じブロックに同じ種類があればそれを選ぶ。右パネルの一覧で値・メモを変え、消す。ブロックを消すと、そのブロックの仮の入出力も消す（元に戻すと戻る）。3D・2Dでブロックに印（動力源は緑、負荷は橙、物の入口は青）を出す。物の入口のアイテムは、名前か ID を打って候補から選ぶ。計算結果とプローブでは、出どころを「仮の入出力」と出す |
| 置く | B | ブロックを置く・置き換える。ドラッグで一直線に置く |
| 消す | E | ブロックを消す |
| スポイト | I | クリックしたブロックを「置くブロック」にする |

## 強調

強調は1種類だけ出す（#163）。新しく強調すると、前の強調は消える。強調しているブロック以外は薄く描くか、枠や色で示す。

| 強調 | 出し方 | 示し方 |
| --- | --- | --- |
| ネットワーク | ネットワークのツール（C）かプローブ（P）でクリック。右パネルの問題やネット一覧の行を押す | 回転でつながったブロックを青緑で示す |
| 同じブロック | 同じブロックのツール（S）でクリック | 隣り合う同じブロック状態のまとまりに枠を付ける |
| ブロック一覧 | 左パネルのブロック一覧で行を押す | その ID のブロック以外を薄く描く |

- Esc か、上のバーの「強調を解除」で、すべての強調を消す
- プローブと同じブロックのツールは、ほかのツールに替えると強調を消す。ネットワークのツールとブロック一覧の強調は、替えても残る

## キー操作

| キー | 操作 |
| --- | --- |
| V / M / C / S / P / O / B / E / I | ツールの切り替え |
| R | 水平に回す（north→east→south→west、軸は x↔z）。範囲なら右回りに 90° |
| Shift+R | 縦にする（軸 y、facing up/down）。範囲なら左回りに 90° |
| Ctrl+R / Ctrl+Shift+R | 範囲を回す。ほかのブロックに重なっても上書きする |
| Ctrl+Z / Ctrl+Y | 元に戻す / やり直す |
| Ctrl+S | 書き出し（.nbt）を始める。ブラウザのページの保存はしない。入力欄で打っても書き出す |
| Delete | 選択中のブロック（範囲）を消す |
| F | 範囲を置くブロックで塗る |
| 矢印キー | 範囲を水平に1マス動かす |
| Shift+PageUp / Shift+PageDown | 範囲を上下に1段動かす |
| Ctrl+A | 設計図全体を選ぶ |
| Ctrl+C / Ctrl+X / Ctrl+V | 範囲のコピー / 切り取り / 貼り付け |
| Ctrl+D | 範囲の複製 |
| G | グリッドの表示切り替え |
| 1〜9 | クイックバーのその番号のブロックを置くブロックにする |
| PageUp / PageDown | 段の移動 |
| ホイール | 拡大・縮小（2D） |
| 空白キー＋左ドラッグ / 中ボタンでドラッグ | 表示を動かす（2D） |
| Esc | 選択とすべての強調の解除。貼り付けの途中なら、貼り付けをやめるだけ |

R / Shift+R は、2つ以上のマスの範囲を選んでいるときは（どのツールでも）、範囲を右・左に 90° 回す（「範囲の選択と一括操作」）。それ以外は、置くツールのときは置くブロックを回す。ほかのツールでは、選択中のブロックがあればそのブロックを（元に戻せる操作として）回し、なければ置くブロックを回す。回せる向きがなければ、下の状態表示に「このブロックには回せる向きがありません」と出す。Modpackを読んでいれば、そのブロックが取りうる値の範囲で回す。

## プロトタイプについて

- `prototype/index.html` をChromeかEdgeで開くと動く。Three.js を CDN から読み込むので、ネット接続が必要
- 例として入っている設計図は、コードで生成したデータ（小さな加工ラインのデモ、負荷テスト、新規）だけ。他人が作った設計図は含めない。デモの配置は見た目の例で、ゲームで動くことは確かめていない
- 書き出しは、`.nbt` を作って読み直し、配置と状態が一致するかの確認までは全環境で動く。保存はブラウザが保存先の選択に対応している場合だけ
- 計算、Modpackの読み込み、範囲操作は未実装（アプリの範囲操作は #129）
